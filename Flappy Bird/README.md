# 🐦 Fleppy Berd

A fun and quirky Pygame-based clone of the classic Flappy Bird game — built entirely with Python and Pygame.

---

## 👾 How to Play

You can run this game directly without Python by using the prebuilt executable. Follow the steps below:

---

### 🔽 Step 1: Download the Game Executable

📦 [Click here to download the .exe file](https://drive.google.com/file/d/1IdwUk0sPzztB4c1lhUlUu1MF07vfTyX5/view?usp=drive_link)

---

### 📁 Step 2: Download the `Assets` Folder

- Download the `Assets` folder from this repository.
- Place it **in the same directory** as the `.exe` file you just downloaded.

> ✅ The game needs the `Assets` folder to run correctly — it contains all the images, sounds, and other resources.

---

### 🧭 Step 3: Run the Game

- Double-click the `.exe` file to start the game.
- You do **not** need Python installed on your system.

---

### 📂 Step 4: Copying the Game Elsewhere (Optional)

If you want to move the game to a different folder or share it:

- Copy **both** the `.exe` file **and** the `Assets` folder.
- Make sure they stay in the **same directory**.

> ❗ Without the `Assets` folder, the game will not launch properly.

---

### 🛠️ Notes

- The executable was created using [`PyInstaller`](https://www.pyinstaller.org/).
- Tested on Windows systems. No external dependencies are required for the `.exe` version.



## 🎮 Features

- Simple yet addictive gameplay
- Click space bar to jump or fly
- Custom animations and sound effects
- Game states: Intro, Playing, and Game Over
- Score tracking and replay functionality
- Smoke effect on bird collision
